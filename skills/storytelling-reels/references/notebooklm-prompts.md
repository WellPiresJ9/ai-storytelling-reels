# Perguntas para o NotebookLM (cole uma por vez, na ordem)

Substitua <PÚBLICO>, <PALAVRA> e <ISCA> antes de colar.

## 1. Extrair o case
```
Com base só neste vídeo, encontre a história real mais forte para contar a <PÚBLICO>.
Me responda em tópicos:
- Personagem (quem sofre o problema)
- O problema em uma frase
- UM momento concreto que mostra o problema (horário, valor em R$, ferramenta, quem estava envolvido)
- O custo de repetir isso (tempo, dinheiro, assinatura, cliente perdido)
- A virada (o que a pessoa percebeu)
- A solução/sistema e o que ele faz no dia a dia
- O resultado (antes x depois, com número se tiver)
Cite o trecho do vídeo de cada item.
```

## 2. Achar a metáfora
```
Me dê 3 metáforas visuais simples (que dá pra desenhar em uma cena) para explicar esse problema.
Exemplo de nível que eu quero: "empresa é encanamento; o entupimento era o dono".
Diga qual é a melhor e por quê.
```

## 3. Roteiro em 6 cenas
```
Escreva um roteiro de storytelling narrado para Reels de ~50 segundos (120 a 140 palavras), em português do Brasil, falado como uma conversa, com frases curtas.
Use exatamente 6 cenas:
1. Gancho: apresenta o personagem e o problema
2. Incidente: o momento concreto (com hora/valor)
3. Escalada: o custo se repetindo
4. Virada: a metáfora
5. Sistema: a solução funcionando
6. Resultado + CTA: "Comenta <PALAVRA> que eu te mando <ISCA>."
Para cada cena, dê: (a) o texto narrado e (b) uma descrição visual da cena em 1 frase, sem nenhum texto escrito na tela.
Nada de inventar fatos que não estão no vídeo.
```

## 4. Cortar
```
Agora corte 25% das palavras sem perder os números, nomes e a metáfora. Cada frase deve ter no máximo 12 palavras.
```

## 5. (Opcional) Teste de gancho
```
Me dê 5 versões alternativas só para a primeira frase da cena 1, cada uma com no máximo 8 palavras, que façam alguém parar de rolar o feed.
```
